# Chatonic AI

Chatonic AI is a simple AI chatbot app made using Flutter and Django.

## Features

- Chat with AI
- Simple and clean UI
- Fast responses
- Flutter frontend
- Django backend

## Tech Stack

- Flutter
- Dart
- Django
- Python

## Run Project

### Frontend

```bash
flutter pub get
flutter run
```

### Backend

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
